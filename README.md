# Ivy Auxilio — Portfolio

React 18 + TypeScript + Tailwind CSS 3 + Vite.

## Setup

1. Install Node.js 18 or newer.
2. `npm install`
3. `npm run dev` and open http://localhost:5173
4. `npm run build` for a production build in `dist/`, `npm run preview` to test it.

## Make it yours

- Projects, skills, email and social links: `src/data/projects.ts`
- Colors and fonts: `tailwind.config.js` (midnight and lavender scales)
- About text: `src/sections/About.tsx`

## Deploy

Upload `dist/` to Netlify, Vercel or any static host.
